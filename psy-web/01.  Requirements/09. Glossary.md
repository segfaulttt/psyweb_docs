# Overview

This document defines key terms used throughout the system to ensure consistent terminology across documentation and implementation.

---

# A

## Active (User Status)
A state indicating that a user is fully approved and can use platform features.

---

# B

## Booking
A confirmed appointment between a client and a specialist for a specific time slot.

---

## Business Rule
A system-wide rule that defines constraints and logic that must always be enforced.

---

# C

## Client
A user who searches for specialists and books consultations.

---

## Chat
An optional communication channel between a client and a specialist.

---

## Consultation Service
A service offered by a specialist defining type, duration, and conditions of consultation.

---

# S

## Specialist
A verified professional providing consultation services on the platform.

---

## Slot (Availability Slot)
A time interval defined by a specialist during which clients can book appointments.

---

## Service
See Consultation Service.

---

# A

## Appointment
A scheduled booking between a client and a specialist linked to a specific slot and service.

---

## Availability
Set of time slots defined by a specialist when they are available for consultations.

---

# R

## Review
A feedback entry submitted by a client after a completed appointment.

---

## Role
Defines user type and access level within the system (Client, Specialist, Administrator).

---

# U

## User
A general system entity representing any person registered on the platform.

---

## Use Case
A structured description of a system interaction scenario between an actor and the system.

---

# P

## Pending Approval
Status indicating that a specialist account is awaiting administrator review.

---

# N

## Notification
System message sent to users regarding updates such as bookings, cancellations, or approvals.

---

# Notes

- This glossary must evolve together with the system.
- All backend entities, DTOs, database tables, and API endpoints should follow this terminology.
- Any ambiguity in naming must be resolved using this document as a source of truth.
