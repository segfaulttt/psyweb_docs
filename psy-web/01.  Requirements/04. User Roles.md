# Overview

The platform supports three primary user roles.

Each role has a defined set of permissions and capabilities.

---

# 1. Client

## Description

A Client is a registered user who searches for specialists and books consultations.

## Capabilities

- manage personal profile;
- browse specialists;
- search specialists;
- filter specialists;
- view specialist profiles;
- view available services;
- book consultations;
- cancel future appointments;
- view appointment history;
- view upcoming appointments;
- communicate with specialists through chat (if enabled);
- leave reviews after completed consultations.

## Restrictions

Clients cannot:

- manage specialist profiles;
- manage services;
- manage appointment availability;
- moderate reviews;
- perform administrative actions.

---

# 2. Specialist

## Description

A Specialist is a verified professional providing consultation services through the platform.

## Capabilities

- manage public profile;
- manage education and certifications;
- manage consultation methods;
- manage services;
- manage availability;
- manage consultation policies;
- publish or hide profile;
- manage appointment schedule;
- cancel appointments;
- communicate with clients through chat.

## Restrictions

Specialists cannot:

- approve specialist applications;
- moderate reviews;
- perform administrative actions;
- manage other specialists.

---

# 3. Administrator

## Description

An Administrator manages and maintains the platform.

## Capabilities

- review specialist applications;
- approve specialists;
- reject specialist applications;
- manage user accounts;
- deactivate specialist profiles;
- moderate reviews;
- access platform statistics.

## Restrictions

Administrators do not provide consultation services through the platform.
