# User Stories

**Status:** Draft

**Version:** 1.0

**Last Updated:** 2026-07-03

---
## Client

### US-001

As a client, I want to register an account so that I can use the platform.

---

### US-002

As a client, I want to browse specialists so that I can choose the most suitable one.

---

### US-003

As a client, I want to filter specialists by specialization so that I can find professionals matching my needs.

---

### US-004

As a client, I want to view a specialist's profile so that I can evaluate their qualifications and experience.

---

### US-005

As a client, I want to view available appointment slots so that I can choose a convenient time.

---

### US-006

As a client, I want to book an appointment so that I can schedule a consultation.

---

### US-007

As a client, I want to cancel a future appointment so that I can change my plans.

---

### US-008

As a client, I want to view my appointment history so that I can keep track of previous consultations.

---

### US-009

As a client, I want to leave a review after a completed consultation so that I can share my experience.

---

### US-010

As a client, I want to communicate with a specialist through chat so that I can ask questions before the consultation.

---

## Specialist

### US-011

As a specialist, I want to submit a registration request so that I can join the platform.

---

### US-012

As a specialist, I want to manage my public profile so that clients can learn about my qualifications.

---

### US-013

As a specialist, I want to create consultation services so that clients can choose the type of consultation they need.

---

### US-014

As a specialist, I want to manage my availability so that clients can book convenient time slots.

---

### US-015

As a specialist, I want to manage consultation policies so that clients understand my working rules.

---

### US-016

As a specialist, I want to view my appointment schedule so that I can plan my work.

---

### US-017

As a specialist, I want to cancel appointments when necessary so that my schedule remains accurate.

---

### US-018

As a specialist, I want to enable or disable chat so that I can choose how clients communicate with me.

---

## Administrator

### US-019

As an administrator, I want to review specialist applications so that only verified professionals appear on the platform.

---

### US-020

As an administrator, I want to approve or reject specialist applications so that I can maintain platform quality.

---

### US-021

As an administrator, I want to manage user accounts so that I can resolve issues and enforce platform rules.

---

### US-022

As an administrator, I want to moderate reviews so that inappropriate content is removed.

---

### US-023

As an administrator, I want to view platform statistics so that I can monitor system activity.
